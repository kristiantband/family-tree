Settings and storage

Where your tree is saved

Connect a private GitHub repository to keep the tree off this page’s public code. The app reads and writes one JSON file in that repo using a token you paste here. The token is stored only in this browser.

How to create the token
  1. On GitHub, go to Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories, and pick your private data repo.
  3. Permissions → Repository permissions → Contents: Read and write. Nothing else is needed.
  4. Generate it, copy it, and paste it above. Keep a copy in your password manager for other devices.
